## What I Learned
. Short passwords are very easy to crack.
. Dictionary words make passwords weak.
. Personal information reduces security.
. Long and random passwords are stronger.
. Using symbols, numbers, uppercase and lowercase improves security.

##  Common Password Attacks

Brute Force Attack:
Trying all possible combinations until the password is found.
Dictionary Attack:
Using common words and password lists to guess passwords.

Password strength depends on:
